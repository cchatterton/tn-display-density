# Changelog

## 0.5.2 - 2026-10-25

- Show the current effective scaling as a small DDS item in the WordPress admin bar.

## 0.5.1 - 2026-10-25

- Replace each pair of application checkboxes with one Frontend, WordPress admin, or Both control.
- Preview the current calibration in the selected area, with separate previews when Both is selected.

## 0.5.0 - 2026-10-25

- Add separate frontend and WordPress admin defaults for Windows and Mac.
- Let each current or saved display calibration apply to the frontend, admin, or both.
- Migrate the previous global scope into the new per-calibration settings without changing existing behaviour.

## 0.4.2 - 2026-10-25

- Remove helper text beneath saved display calibrations to keep each row compact.

## 0.4.1 - 2026-10-25

- Replace the saved-scenario table and nested calibration cards with compact, full-width rows.
- Remove repeated headings and instructions from the saved section.
- Remove the optional scenario name field; preserve labels already stored on saved scenarios.

## 0.4.0 - 2026-10-25

- Move sliders in 0.1 increments while retaining precise numeric entry.
- Preview the current display calibration temporarily on the site homepage.
- Choose frontend-only or frontend-and-admin scaling.

## 0.3.0 - 2026-10-25

- Move Display Density to Appearance and introduce the branded admin layout.
- Add drag sliders paired with exact numeric inputs for defaults and saved scenarios.

## 0.2.1 - 2026-10-25

- Remove arbitrary calibration limits while rejecting invalid values and non-positive calculated zoom.

## 0.2.0 - 2026-10-25

- Add per-display scenario calibration controls for Windows and macOS.

## 0.1.2 - 2026-10-25

- Apply the optional Mac factor only when device pixel ratio drops below Retina range.

## 0.1.1 - 2026-10-25

- Clarify the plugin's display-scaling purpose in its metadata and settings screen.

## 0.1.0 - 2026-10-25

- Add Windows inverse-DPR compensation and direct macOS zoom setting.
- Add Settings > Display Density.
